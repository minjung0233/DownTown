# DownTown

A Unity prototype focused on a simple item inventory. The project contains scripts for game management, inventory, items, and inventory slots, along with scenes and inventory assets.

## Project contents

- `GameManager.cs` — game-level coordination
- `Inventory.cs` — inventory logic
- `Item.cs` — item data and behavior
- `Slot.cs` — inventory slot behavior
- `Assets/Scenes` — Unity scenes
- `Assets/Item_Obj` and `Assets/RPG_inventory_icons` — item and inventory assets

## Status

This is an unfinished prototype. The latest repository activity records a basic inventory implementation; there is no packaged release.

## Open the project

1. Open the `DownTown/` folder in Unity Hub.
2. Use the Unity version recorded in `DownTown/ProjectSettings/ProjectVersion.txt`.
3. Open the included scene from the Unity Editor.
